下面按推荐的 **Windows + PM2 + 局域网访问** 方式部署。PackHub 最终会运行在：

```text
http://Windows电脑IP:3001/
```

## 一、准备环境

### 1. 安装 Git

下载并安装 Git：

```text
https://git-scm.com/download/win
```

安装完成后打开 PowerShell，检查：

```powershell
git --version
```

### 2. 安装 Node.js 24

PackHub 使用 Node.js 内置 SQLite，必须安装 **Node.js 24 或更高版本**。

下载地址：

```text
https://nodejs.org/
```

安装后重新打开 PowerShell，检查：

```powershell
node --version
npm --version
```

确保 Node.js 版本类似：

```text
v24.x.x
```

## 二、下载 PackHub

建议将项目部署到：

```text
D:\PackHub
```

打开 PowerShell：

```powershell
cd D:\
git clone https://github.com/wxQTFY/packhub.git PackHub
cd D:\PackHub
```

安装依赖：

```powershell
npm install --include=dev
```

## 三、配置环境变量

PackHub 当前不会自动读取 `.env` 文件，需要配置 Windows 环境变量。

### 1. 生成 JWT 密钥

在 PowerShell 中执行：

```powershell
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

复制输出的随机字符串。

### 2. 设置永久环境变量

将下面的密钥替换为刚才生成的字符串：

```powershell
setx PORT "3001"
setx MAX_UPLOAD_MB "1024"
setx JWT_SECRET "替换为生成的随机字符串"
```

`MAX_UPLOAD_MB=1024` 表示单个安装包最大允许上传 1024 MB。

设置完成后，关闭当前 PowerShell，重新打开一个 PowerShell 窗口。

检查环境变量：

```powershell
echo $env:PORT
echo $env:MAX_UPLOAD_MB
echo $env:JWT_SECRET
```

## 五、首次启动测试

执行：

```powershell
npm start
```

```text
http://localhost:3001/
```

默认管理员：

```text
账号：admin

```

测试完成后，在 PowerShell 中按：

```text
Ctrl + C
```

停止测试服务。

## 六、使用 PM2 后台运行

PM2 可以让 PackHub 在命令窗口关闭后继续运行，并在服务崩溃后自动重启。

进入项目目录执行：

```powershell
cd D:\PackHub
npm run pm2:start
```

查看运行状态：

```powershell
npm run pm2:status
```

查看日志：

```powershell
npm run pm2:logs
```

确认状态为：

```text
online
```

保存 PM2 当前运行状态：

```powershell
npx pm2 save
```

现在关闭 PowerShell，PackHub 仍会继续运行。

## 七、配置 Windows 开机自启动

推荐使用 Windows 任务计划程序。

### 1. 打开任务计划程序

按 `Win + R`，输入：

```text
taskschd.msc
```

点击“创建任务”。

### 2. 常规设置

填写：

```text
名称：PackHub
```

勾选：

```text
使用最高权限运行
不管用户是否登录都要运行
```

### 3. 设置触发器

新增触发器：

```text
开始任务：启动时
延迟任务时间：30 秒
```

### 4. 设置操作

新增“启动程序”操作：

程序或脚本：

```text
C:\Windows\System32\cmd.exe
```

添加参数：

```text
/c "cd /d D:\PackHub && npx pm2 resurrect"
```

起始于：

```text
D:\PackHub
```

保存任务后，可以重启 Windows 验证 PackHub 是否自动启动。

## 八、开放 Windows 防火墙

以管理员身份打开 PowerShell，执行：

```powershell
netsh advfirewall firewall add rule name="PackHub 3001" dir=in action=allow protocol=TCP localport=3001
```

查看部署电脑局域网 IP：

```powershell
ipconfig
```

找到当前网卡的 IPv4 地址，例如：

```text
192.168.1.20
```

局域网其他电脑访问：

```text
http://192.168.99.135:3001/
```

## 十一、数据备份

PackHub 的重要数据位于：

```text
D:\PackHub\server\data\packhub.sqlite
D:\PackHub\server\uploads\
```

建议备份前先停止服务：

```powershell
cd D:\PackHub
npm run pm2:stop
```

然后复制以下内容：

```text
server\data\packhub.sqlite
server\uploads\
```

备份完成后重新启动：

```powershell
npm run pm2:start
npx pm2 save
```

日志目录：

```text
D:\PackHub\logs\
```

完成以上步骤后，PackHub 就可以在 Windows 局域网环境中长期运行。
